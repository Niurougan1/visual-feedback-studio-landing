InstallFree Local本地工作流

Run the review loop on your machine.在你的机器上跑完审稿闭环。

Install the local receiver and browser companion for localhost, preview servers, and solo agent loops.安装本地 receiver 与浏览器 companion，用于 localhost、预览服务器和个人 agent 闭环。

ModeNo team account required. Source, tokens, local paths, and environment variables stay local.无需团队账号。源码、token、本地路径与环境变量留在本机。
01Command安装命令

One command. One local receiver.一条命令，一个本地 receiver。

Use this for localhost and solo agent loops. The command installs the public receiver workflow and companion setup from the public package path.用于 localhost 和个人 agent 闭环。命令会安装公开 receiver 工作流与 companion 设置。

curl -fsSL https://raw.githubusercontent.com/Niurougan1/visual-feedback-studio/main/scripts/install.sh | bash
02Port override端口覆盖

When 3456 is already taken.当 3456 已经被占用。

Run the installer with a custom receiver port. Use this when another local service already owns the default port.用自定义 receiver 端口运行安装器。适合默认端口已经被其他本地服务占用的情况。

curl -fsSL https://raw.githubusercontent.com/Niurougan1/visual-feedback-studio/main/scripts/install.sh | VFS_PORT=3463 bash
03What installs安装内容

The pieces stay separate on purpose.这些部分有意保持分离。

R

Local receiver本地 receiver

Receives accepted feedback from the browser workflow and keeps local context on your machine.接收浏览器工作流里的已接受反馈，并把本地上下文留在你的机器上。

C

Chrome companion pathChrome companion 路径

Captures visual feedback on the real tab, including localhost and authenticated pages you authorize.在真实标签页捕捉视觉反馈，包括你授权的 localhost 与登录态页面。

A

Agent-ready handoffAgent 可用交接

Turns accepted review intent into target context your coding agent can apply and you can verify.把已接受审稿意图转成 coding agent 能应用、你能验证的目标上下文。
