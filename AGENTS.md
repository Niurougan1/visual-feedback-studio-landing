# Repository Instructions

## Repository Scope

This repository contains the public marketing page for Visual Feedback Studio. Keep it focused on the landing page experience: page structure, visual design, copy, CTA behavior, analytics snippet, and public assets.

Operational rules:

- Landing page UI, copy, CTA buttons, analytics, and visual assets belong here.
- Do not add product implementation, unpublished planning, roadmap material, release submissions, review notes, non-public names, URLs, aliases, or role maps.

## Editing

- Keep `index.html` self-contained except for assets stored in `assets/`.
- When changing the setup CTA, update all visible command text and the JavaScript copy value together.
- Keep the setup command one line and easy to copy.
- Preserve the existing visual direction unless the user asks for a redesign.

## Verification

- Search `index.html` after CTA changes to confirm visible command blocks and copy-button values match.
- Check responsive layout for desktop and mobile when changing structure, typography, or media.
